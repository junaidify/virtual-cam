VirtualCam — Privacy Policy

Last updated: July 8, 2026

Overview

VirtualCam ("the Extension") is a browser extension that allows users to use a pre-captured photo as their webcam feed. This privacy policy explains how the Extension handles user data.

Data Collection

We do not collect, transmit, or share any user data.

The Extension does not:

  • Send any data to external servers
  • Track user activity or browsing history
  • Use analytics or telemetry
  • Collect personally identifiable information
  • Communicate with any remote services

Data Storage

The Extension stores the following data locally on your device only, using Chrome's built-in chrome.storage.local API:

  • Your uploaded image — Stored as a base64-encoded JPEG, used solely to generate the virtual camera feed. This image never leaves your device.
  • Extension settings — A simple on/off toggle preference.

All stored data can be cleared at any time by clicking "Clear Image" in the Extension popup, or by uninstalling the Extension.

Permissions

The Extension requests the following browser permissions:

  • storage — To save your uploaded image and settings locally.
  • scripting — To inject the virtual camera script into web pages so they receive the virtual feed.
  • Host permissions (all URLs) — Required so the virtual camera works on any website that requests camera access.

Third-Party Services

The Extension uses no third-party services. The Google Fonts stylesheet referenced in the popup UI is loaded directly from Google's CDN for typography only.

Changes to This Policy

Any changes to this privacy policy will be reflected with an updated date at the top of this page.

Contact

For questions or concerns about this privacy policy, please open an issue on the Extension's GitHub repository or contact the developer directly.
